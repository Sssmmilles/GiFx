### About
Shortly: GiFx is a GIF editor that lets you edit GIFs and create them from images and videos.
- How to Use: Download and open [index.html](index.html) in a modern browser, or use from <https://Sssmmilles.github.io/GiFx/>.

----
### Features
- **Creating** — Create GIFs from images and videos.
- **Tools** — Optimize, resize, crop, brightness, contrast, saturation, hue, blur, pixelate, grayscale, sepia, invert, color replacement, text overlay, and more.
- **Interface** — Customizable interface: Background color, accent color, and border radius.
